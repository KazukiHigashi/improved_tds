# Claude 外部監査と対応記録（2026-10-08）

ユーザーの明示承認後、ローカル Claude Code 2.1.293 から `claude-opus-5-5`、High Effort、読み取り専用 `Read` の非対話モードで3回監査した。送付範囲は指定した研究コード、実験 manifest、結果 JSON、報告 HTML（1回目）、報告生成コード（2・3回目）のみで、元論文 PDF、秘密ファイル、リポジトリ全体は送っていない。Claude に編集・コマンド実行・Web閲覧は許可していない。

## 監査の限界

1回目は `index.html` の本文がほぼ1行で長く、Claudeの読み取り上限にかかり、HTML本文を精査できなかった。2回目は報告生成コードの日本語本文を読ませた。3回目は新しい9目標の集計コード・集計JSON・status・未知ツール実行コードの4ファイルだけを読ませた。生の試行JSONとHTMLの表示状態はClaudeの3回目の監査対象外である。限定ファイルの監査は研究不正が存在しないことの証明ではない。以下はClaudeの指摘とCodexによる原資料の照合・対応を区別して記す。

## 報告文への指摘

実験手順と誤差指標の読み方は、[論文用統合HTMLの手順フローチャート・誤差計算図](../analysis/paper_ff_fb_generalization_20261008/index.html#visual-guide)に直接追加した。同じ図は[共通9目標の再評価HTML](../analysis/matched_nine_goals_clipped_20261008/index.html#procedure)にも掲載した。図は凍結済みデータからFF・未知ツール転用・FBへ分かれ、同じ8評価初期姿勢×9目標へ合流する最新の再評価を表す。目標と実測の差を各ツールのRL目標幅で割り、完走・有限終端の試行で平均する計算を、保存済みScissors 3の実測値で追えるようにした。旧実験の目標域・試行数とは区別して記述し、試行結果や採否基準は変更していない。

Claudeは、TDS・RL・SAC・HER・DB・NN・PC1/PC2などの略語、独立スイープ、等張回帰、ランプ関数、逆写像可能域、採用／保持／有効の違いが初出で不明確と指摘した。特にPushは角度ではなく変位[m]であり、全カテゴリを一律に「角度」と呼ぶのは誤りである。また「PLS主成分得点」より「軸上の得点」が適切である。1自由度FFの式には軸の尺度係数が必要で、CoverageはRL目標範囲で切り詰めた到達幅である。本文は「用語→方法→比較可能な数値→限界」の順に改稿する。

1回目監査の「オフライン図が表示されない」という疑いは、生成コードにSVGフォールバックがあるため誤検知だった。図の実表示自体はClaudeに確認させていない。

## 再現性

今回の再評価に使用した実行環境は Python 3.12.10、NumPy 2.4.6、SciPy 1.17.1、scikit-learn 1.9.0、MuJoCo 3.9.0、Gymnasium 1.0.0、Stable-Baselines3 2.8.0。外部 `tool-manip-gym` はコミット `acec1eb87ecf1c0a9d6cd4a5937d48858c04c4dc` のクリーンな `experiment/paper-lite-ablation-envs` ブランチである。ただし、過去の学習時にも同一の外部環境コミットだったと独立に証明できていない。旧の機械可読再集計に含まれた個人の絶対パスは、生成時にリポジトリ相対パスへ置き換える。

投稿前には、第三者メッシュ・STL等のライセンス表示と、使用したAI支援の開示方法を投稿先の規程に照らして確認する。Claudeの指摘は確認事項であり、現時点でライセンス違反や研究不正を認定したものではない。

## 新しい共通9目標の結果監査と対応

全34ジョブが完了した再評価の集計を、Claudeが3回目の限定監査で点検した。数値13/15ツールの単純平均改善、8/15ツールの15プローブ、Spray 3/5ツールが27.78%以上、欠測FF 1・未知ツール0・FB 3は集計JSONとの一致を確認した。ただし、FBのFF条件はFF本体と同じ試行であり、欠測件数を合算して独立な4件と数えない。

| 論点 | 照合結果・対応 |
|---|---|
| 較正不成立の隠れた代替 | Spray 1の共通軸3点較正は不成立で、実測なしの線形逆写像へ戻る。表に較正失敗の列を設け、3点較正成功と誤読しないよう説明した。選択軸の較正は全15件で成立した。 |
