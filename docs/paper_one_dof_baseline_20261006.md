# 論文用ベースライン：PCA／PLSによる1自由度TDS制御

この文書は、15タスクの選定済み実験から**1自由度制御だけ**を抽出した論文用の基準点である。数値の出典は `analysis/paper15_paper_bundle_20260928/` の各 `report.json` と `manifest.json`。後日の可変把持スコア実験を混ぜていない。集計は `python scripts/summarize_paper_one_dof.py` で再計算・ハッシュ照合できる。ここでいう「1自由度」は目標姿勢を決める独立なスカラー入力が1つという意味であり、ハンドの物理アクチュエータ数ではない。

## 実験方法と条件

- Scissors、Push、Sprayの各5変種、計15タスク。選定済みの学習キャンペーンは `runs/paper15_unified_3m_slew_20260927`。各タスクの成功最終姿勢DBは200件で、選定済みベストポリシーから収集された。
- 同じDBの姿勢200件を全体平均で中心化する。PCAは第1主成分、PLSは実測ツール状態に対する1成分の教師あり軸を操作方向とし、ツール応答に対して正向きへ符号をそろえる。評価中は第2軸のスコアを0に固定する。
- 成功姿勢の平均を `q̄`、操作方向を `s`、唯一の操作スコアを `ρ` として、目標姿勢を `clip(q̄ + ρ s)` で作る。保存済み初期姿勢から目標姿勢まで各関節へ5秒間の線形軌道指令を送り、終点で2秒保持する。TDS評価中にRLポリシーやツール状態のフィードバックは使わない。
- 較正には8初期姿勢、各17スコアを用いる。スコア範囲は成功姿勢の主成分得点の最小・最大をそれぞれ1.5倍したもの。測定応答の単調な区間で等張回帰とランプ関数を較正し、逆写像可能な範囲内の9目標を、別の8初期姿勢で検証する。初期姿勢IDは較正と評価で異なるが、レポートの `unseen_pose_evaluation` フラグは `false` であり、未知の姿勢分布への一般化とは主張しない。
- ScissorsのRL・DB成功判定はPalm追従球の元の半径0.05 mを用いる。選定済みTDS較正・評価では半径を1.5倍した0.075 mとし、はさみのヒンジ中心が球内にあることを姿勢採用条件とする。Push／SprayのTDSでは接触数を採否条件にせず、落下・転倒を除外する。Sprayの床接触は有効。RL成功、成功姿勢DBへの採用、TDS較正・評価での採用は同一条件ではないため、論文中では分けて記述する。

## 選定済み1自由度結果

5変種の単純平均。逆写像可能幅と独立スイープCoverageは、各タスクのRL目標範囲幅で正規化した。MAEは等張回帰に基づく**有効な未知目標試行のみ**の誤差を同じ幅で正規化した値である。`保持/試行` は5タスク合計で、RLタスク成功率ではない。

| カテゴリ | 軸 | 逆写像可能幅 | 独立スイープCoverage | 保持MAE | 保持/試行 |
|---|---|---:|---:|---:|---:|
| Scissors | PCA | 83.20% | 86.37% | 4.83% | 359/360 |
| Scissors | PLS | 91.83% | 92.16% | 4.24% | 356/360 |
| Push | PCA | 73.74% | 73.92% | 8.18% | 360/360 |
| Push | PLS | 99.21% | 98.92% | 6.60% | 360/360 |
| Spray | PCA | 65.12% | 66.30% | 7.68% | 360/360 |
| Spray | PLS | 67.33% | 64.94% | 8.31% | 360/360 |

PLSはPushで操作可能幅を大きく拡張した。SprayではMAEがPCAより大きく、PLSの一律優位は主張できない。また各方式のMAEはそれぞれの逆写像可能範囲内で測るため、厳密には同じ目標点の誤差比較ではない。論文の最終比較には、共通目標点でのMAE、全RL目標幅に対するCoverage、無効試行率を並記する。8初期姿勢×9目標の72試行を72個の独立した姿勢条件とみなさない。

## 出典と再現

選定済みバンドルの `manifest.json` SHA-256：`0f91d3853eb90080649de62dc2ae77d3d5ac5daf660011ae8c61b3e903e6733d`。集計スクリプトは15件の選定済みレポートのSHA-256、DB件数、5秒＋2秒の条件、1自由度結果の試行数を確認してから出力する。

```powershell
python scripts/summarize_paper_one_dof.py
python scripts/summarize_paper_one_dof.py --json
```

`analysis/` と `runs/` は容量のためGit追跡外だが、ローカルに保存済みである。新しい環境で数値を再生成するにはバンドル、学習済みモデル、DBを別途復元する。従来の `main` に存在する2軸候補の解析コードは過去の記録として残すが、このベースラインの論文主張と表には使わない。第2軸によるフィードバック制御は別ブランチの探索的実験とする。
