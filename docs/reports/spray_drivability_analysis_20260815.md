# spray3〜5学習失敗の追加調査と改善方針

作成日: 2026-08-15
前提資料: `spray_training_failure_report_20260814.md`（Codex作成）

## 要旨

前回レポートは「初期姿勢DBが非駆動である」ことを主因と判定した。これは正しい。
本調査ではその**一段下の原因**を特定した。

1. **駆動判定の指標が誤っている。** 現在のゲートは`travel = max - min`で、
   トリガーの受動的な揺れを能動駆動と区別できない。spray1は「32/32合格・
   travel 0.0358 rad」だが、**能動ゲインは0.0000 rad**である。合格は重力による
   垂れ下がりだけで得られていた。
2. **spray1のトリガー慣性記述が誤っている。** 重心が蝶番から221 mm離れており
   （他variantは9〜19 mm）、常時0.04 radの重力垂れを生む。spray1の23%成功は
   この垂れと低角目標の一致による見かけの成功である。
3. **学習側ラッパーが結合関節J1を注入していない。** 保存姿勢とは最大0.50 rad
   ずれた指形状でエピソードが始まる。パイプラインの検証結果が学習へ転送されない。
4. **ボトル形状は問題ではない。** 姿勢探索により、**全5variantで能動ゲイン
   0.16〜0.55 rad**が達成可能であることを確認した。spray1・spray4では
   人差し指がトリガーへ98〜100%のstepで接触し、可動域0.4 radをほぼ使い切る。

したがって改善は「モデルを作り直す」ではなく「**判定指標を直し、基準姿勢を
その指標で作り直す**」で足りる。

## 検証結果

### 1. 学習環境・現行DBでの能動駆動（本調査）

パイプラインと同じ駆動指令（姿勢＋可動域50%をFF系アクチュエータへ）を
学習環境へ与え、同一状態からの受動走行と比較した。8姿勢の中央値。

| variant | raw travel | 受動 travel | **能動ゲイン** |
| --- | ---: | ---: | ---: |
| spray1 | 0.0358 | 0.0358 | **0.0000** |
| spray2 | 0.2557 | 0.0098 | **0.2640** |
| spray3 | 0.0036 | 0.0031 | 0.0002 |
| spray4 | 0.0014 | 0.0014 | 0.0000 |
| spray5 | 0.0019 | 0.0018 | 0.0000 |

raw travelは前回レポートのQA値（0.0358 / 0.2700 / 0.00316 / 0.00142 / 0.00187）を
再現している。**spray1のtravelは全て受動成分**であり、能動的な制御権限は無い。
実際にspray1の成功軌跡が0.020〜0.072 radに限定される事実と整合する。

### 2. トリガーの重力垂れ

| variant | トリガー質量 | 蝶番→重心 | 重力トルク | 静止角 |
| --- | ---: | ---: | ---: | ---: |
| spray1 | 6.0 g | **221.8 mm** | 8.39 mNm | **0.0399 rad** |
| spray2 | 6.0 g | 9.0 mm | 0.33 mNm | 0.0016 rad |
| spray3 | 6.0 g | 18.7 mm | 0.62 mNm | 0.0035 rad |
| spray4 | 6.0 g | 8.8 mm | 0.31 mNm | 0.0015 rad |
| spray5 | 6.0 g | 14.7 mm | 0.40 mNm | 0.0020 rad |

spray1の`<inertial pos="0.010 0.007 0.150">`は蝶番`pos="0.010 0.176897 0.007493"`から
221 mm離れている。同じXMLのトリガーsiteは蝶番から30 mmなので、慣性記述だけが
外れ値である。siteと同程度の重心なら静止角は0.009 radとなり、現在の1/4以下になる。

### 3. 結合関節J1の注入漏れ

`InitialPosePoolWrapper._inject`は`_actuator_ids`（13個の指令アクチュエータ）に
対してのみ`qpos`を書く。結合追従側の`rh_FFJ1`等は書かれず、環境既定値のまま残る。

| variant | 注入FFJ2 | 実際のFFJ1 | 差 |
| --- | ---: | ---: | ---: |
| spray1 | 0.9051 | 1.2755 | -0.3704 |
| spray2 | 1.2631 | 1.2755 | **-0.0124** |
| spray3 | 0.7800 | 1.2755 | -0.4955 |
| spray4 | 1.0054 | 1.2755 | -0.2701 |
| spray5 | 0.9620 | 1.2755 | -0.3135 |

`ctrl[rh_A_FFJ1]`も同様に古い値のままである。同ファイルには結合をテンドンで
表現していた頃の`_COUPLED_TENDON_JOINTS`分岐が残っており、J2/J1個別
アクチュエータへ変更した際の追従漏れである。

補正すると指先は約5 mm動くが、それだけでは駆動は回復しない（能動ゲインは0のまま）。
**主因ではないが、検証結果を学習へ転送するために必須の修正**である。

### 4. 駆動可能な姿勢は存在する

13関節指令＋ハンドマウント位置（±50 mm）を400回のランダム探索で最適化し、
能動ゲインと人差し指-トリガー接触率を同時に最大化した。

| variant | 能動ゲイン | 到達角 | 指-トリガー接触率 | マウント補正 |
| --- | ---: | ---: | ---: | --- |
| spray1 | 0.4074 | 0.4066 | **100%** | [+27, +50, +8] mm |
| spray2 | 0.0281 | 0.0297 | 0% | [-13, +1, -7] mm |
| spray3 | 0.1593 | 0.1625 | 2% | [-18, -31, +2] mm |
| spray4 | 0.4019 | 0.4202 | **98%** | [-2, +49, -1] mm |
| spray5 | 0.5477 | 0.2959 | 57% | [-22, +43, -10] mm |

探索は既定姿勢から開始しているため、spray2が低いのは開始点が悪いだけである
（spray2は編集済み姿勢で0.264を達成済み）。

**spray1・spray4は可動域0.4 radをほぼ使い切り、接触も98〜100%で持続する。**
補正量はspray1・4・5で+y方向40〜50 mmに集中し、探索上限に達している。
つまり現在の基準姿勢は、ハンドがトリガーに対して系統的に手前へ寄りすぎている。

### 5. 報酬 shortcut の大きさ

現行 `tracking = 2.0 * (1 - error / 0.4)`。

| 目標角 | 無操作方策のtracking | 200stepあたり | 理論最大比 |
| --- | ---: | ---: | ---: |
| 0.04 rad | 1.800 /step | 360 | 18% |
| 0.12 rad | 1.400 /step | 280 | 14% |
| 0.20 rad | 1.000 /step | 200 | 10% |

`exp(-0.5 * (error / 0.03)^2)`へ置き換えると、無操作のtrackingは
0.04 radで0.822、0.12 radで0.0007、0.20 radで0.0000となり、shortcutは消える。

### 6. 関節範囲の逸脱

spray5の探索結果は能動ゲイン0.5477に対し到達角0.2959であり、受動側が
-0.25 radまで振れている。前回レポートの「spray2でtrigger qposが
[0, 0.4]外へ1.77%」と同じ現象で、`limited="true"`が効いていない状況がある。

## 改善方針

### P0: 判定と注入の修正（再学習前に必須）

1. **駆動ゲートを能動ゲインへ変更する。** `travel = max - min`をやめ、
   同一状態から「姿勢保持のみ」と「駆動指令」の2本を走らせ、
   `能動ゲイン = 駆動時ピーク - 保持時ピーク`で判定する。
   受動的な垂れ・揺れを能動駆動と誤認しなくなる。
   合格条件案: 能動ゲイン >= 0.05 rad、指-トリガー接触率 >= 30%、非落下・非転倒。
2. **`generate_spray_lite.py`の`RefineConfig(require_drive=False)`を廃止する。**
   全variantで駆動判定を必須にする（前回レポートP0と同じ）。
3. **`InitialPosePoolWrapper._inject`を結合対応にする。** 追従側J1の`qpos`と
   `ctrl`をJ2から複製する。あわせて残存している`_COUPLED_TENDON_JOINTS`分岐を
   除去する。これを直さないと、パイプラインで検証した姿勢が学習で再現されない。
4. **spray1のトリガー`<inertial pos>`を修正する。** 現在は蝶番から221 mm。
   メッシュ重心またはsite近傍へ置き直し、静止角が0.01 rad未満になることを確認する。
   これを直さないとspray1の成功指標が信用できない。

### P1: 基準姿勢の再編集（GUIマシン側）

spray1・3・4・5を再編集する。spray2は現状を基準として使える。

編集時の目標は「人差し指をトリガー面に載せる」ことに尽きる。具体的な受け入れ条件:

- 人差し指-トリガー距離 <= 40 mm（spray2の実測35 mm、失敗variantは47〜78 mm）
- 駆動中の指-トリガー接触率 >= 30%
- 能動ゲイン >= 0.05 rad
- 零入力20stepでのボトル変位 <= 5 mm

探索結果から、**ハンドを+y方向へ30〜50 mm寄せる**のが最も効く。指の関節角より
先にマウント位置を合わせること。spray3は探索でも接触率2%に留まり最も難しいので、
トリガーの向きとハンドの接近方向を含めて作り直す。

### P2: 報酬の修正

1. trackingを`exp(-0.5 * (error / tolerance)^2)`へ変更する（HERで再計算可能）。
2. tracking/progressを`0.25 + 0.75 * grasp_score`で部分ゲートする。
3. drop/tipは従来通り`-250`で全項を上書きする。

P0・P1を行わずP2だけを行っても解決しない。物理的な駆動経路が無いためである。

### P3: 物理QA

1. trigger qposが`[0, 0.4]`を外れる割合をtelemetryへ追加する。
2. 逸脱が続く場合は`solref`/`solimp`・damping・armatureを見直す。
3. 32姿勢プールの全数QAをCIへ入れ、`require_drive=true`と能動ゲインを
   artifactへ記録する。

## 実施順序の提案

```
P0-1,2,3,4（このマシンで実施可能。GUI不要）
        ↓ 現DBのspray2で回帰確認
P1（GUIマシンでspray1/3/4/5を再編集）
        ↓ 新DBを能動ゲインゲートで生成・全数QA
P2（報酬修正）→ 短時間smoke run → 1M本学習
```

P0-1と P0-3 は、現DBのままでも「spray2は通り、spray1は落ちる」ことを
確認できるので、GUI待ちの間に単独で検証できる。

## 未検証事項

- spray3が探索でも接触率2%に留まる理由。トリガー位置（蝶番が他variantより
  y+90 mm、z-50 mm）が関係する可能性があるが、モデル修正が必要かは未判定。
- P0-3の修正がspray2の学習性能を変えるかどうか（spray2は差が-0.0124 radと
  小さいため影響は小さいと予想されるが、実測していない）。
- 能動ゲインゲートの閾値0.05 radは、spray2の実測0.264とspray4の探索値0.402から
  置いた暫定値であり、再学習で調整が要る可能性がある。
