# Scissors 3–5：低成功率の再調査と v6 再学習（2026-09-21）

## 結論

v5 は単に学習ステップが足りないだけではなく、固定指令での保持を学ぶ入口が狭すぎた。
角度・接触・速度の瞬間成功を達成しても、指令変化量の条件を満たせず保持練習に入らない。
さらに、保持練習の成功回数だけで進むカリキュラムが全ワーカーで第0段階のまま停滞した。
この構造を直したうえで、Scissors 3–5 のみを各300万ステップで新規学習する。
固定指令2秒・角度誤差0.03 rad・ツール速度0.1 rad/sの最終成功条件は緩めない。

またv4/v5は初期接触猶予などが異なるため、上表だけで個々の変更の因果効果を断定しない。

### 確認された主因

1. **保持への入口の欠陥**：v5は瞬間成功に加え、適用指令RMS変化≤0.02、
   根元並進速度≤0.05 m/s、角速度≤0.5 rad/sを10フレーム連続で要求する。
   SACの探索やフィードバックの微修正と両立しにくい。実際、Scissors 3の保存方策は
   今回の比較試験で瞬間成功が多数あるのに、指令変化条件を満たすフレームが0だった。
2. **カリキュラムの停滞**：直近20保持試行の70%以上成功で昇格するため、
   試行自体がないと昇格できない。v5は3タスク×4ワーカーすべて第0段階で終了した。
3. **固定直後の過渡応答を失敗扱い**：v4/v5は固定後の最初の不良フレームで保持試行を失敗とする。
   指令固定後に減速・整定して安定する可能性を十分に試せない。
4. **報酬と研究目的のずれ**：瞬間成功に毎ステップ+5が入り、フィードバックで追従できるだけでも
   高報酬を得られる。固定指令で維持できる姿勢を優先する動機が弱い。
   これは報酬式上のリスクであり、方策が意図的に保持を回避したと断定するものではない。
5. **物理的把持の弱さは残る**：v4最良方策の物理失敗は138/352、197/352、327/352。
   とくにScissors 5は接触喪失が多い。入口修正のみで把持が安定するとは限らない。

## v6 の変更

- 元の瞬間成功条件を3フレーム（0.12秒）連続達成したら固定保持を試す。
  指令変化量・根元速度の追加ハードゲートは撤去する。速度の連続ペナルティと物理破綻判定は維持。
- 固定試行の時間予算を「必要保持時間 + 0.4秒」とする。
  過渡的な角度・速度逸脱では即座に指令を変えず、良好フレームの連続数を0へ戻す。
  最終成功には同一指令下で元の条件を50フレーム連続で満たす必要がある。
  時間予算終了なら試行を中断し、10フレームの再調整期間後に再試行できる。
  接触喪失・落下・過大変位等の物理失敗では待たずに終了する。
- .4 / .8 / 1.2 / 2秒の練習段階は従来の習熟条件に加え、学習予算の20 / 40 / 60%到達後の
  次のエピソード開始時にも昇格する。最後の約40%は2秒のみ。初期段階も20%は2秒試行。
  Validation・姿勢収集は最初から常に2秒であり、短時間の練習達成を成功に数えない。
- 瞬間成功ボーナスの80%を固定指令中へ移す。既定値+5のうち、フィードバック中は+1、
  固定成功中は追加+4と従来の保持報酬+2を得る。成功中の合計は従来と同じ+7。
  短時間練習の達成ボーナスは保持時間/2に比例させ、短い練習の反復を過大評価しない。
  追従・進捗・接触・安全性の連続報酬は残す。
- 保持試行数・完了数・練習成功数・段階を学習ログへ出力。
  数値異常が保持外で生じた場合、それを保持試行失敗として数えない。
- v5の数値異常検出、異常遷移のReplay除外、異常軌跡のDB除外、成功後も指令を固定して
  同じ400ステップ上限まで評価する処理を維持。

Scissors内ではVariant別の係数・成功条件・ルールを設けない。
これはRLによる成功姿勢生成の修正であり、TDS操作に追加自由度やオンラインRLを導入するものではない。

|---|---:|---:|
|Scissors 3|0 → 33|0 → 31|
|Scissors 4|0 → 22|1 → 12|
|Scissors 5|0 → 6|0 → 5|

旧方策を固定したまま入口変更の効果を確認する診断であり、新規学習の性能評価ではない。
Scissors 3はv6環境でも2秒成功0/12であり、固定後の物理安定性を学び直す必要がある。
Scissors 4は探索あり3/12、Scissors 5は決定論的3/12・探索あり1/12成功したが、
少数の選択された姿勢・角度による参考値であり、352試行評価と比較して改善率を主張しない。
比較時と最終実装で報酬分配のみ追加変更したが、保存済み方策の推論と物理遷移には影響しない。

診断データ：`analysis/retention_v6_20260921/entry_comparison.json`

最終コードの全テスト150件通過。3タスク×4環境×4000ステップの短時間学習で、
