# 第2シナジー軸を用いたフィードバック実験：新ブランチの実施条件

ブランチ：`feat/tds-second-axis-feedback-20261006`。比較の固定基準は `main` の [`paper_one_dof_baseline_20261006.md`](paper_one_dof_baseline_20261006.md) と、選定済み15タスクの学習済みポリシー・成功姿勢DBである。学習やDBを変更せず、制御と評価だけを別実験として追加する。以前の可変 `g`・力指標・接触数の実験コードは `feat/tendon-feedback-grasp-20260929` に保存されている。前回の静的 `g` 選択と、今回の実時間フィードバックは別の介入として扱う。

## 仮説

第1軸の逆写像によるFF操作後、第2軸をツール操作量の偏差に応じて小さく動かすと、同じ目標値・初期姿勢・総実行時間で、FFのみ、または第1軸だけを補正する制御より、未知目標の誤差を減らせる場合がある。第2軸を把持専用とは仮定しない。PCAではPC2、PLSではPLS第1軸を取り除いた姿勢残差のPC1を用いる。後者を「PLS第2成分」とは呼ばない。

## 評価手順

1. まず同じ学習結果・DB・環境を使い、Scissors 3・4、Push 3、Spray 3を診断する。各目標に対するFF操作スコア `rho_ff` を固定し、初期姿勢と乱数シードをそろえて `g` を小さく正負に変える。ツール応答 `y(rho_ff,g)`、接触、落下、関節クリップ、保持中のばらつきを記録する。画像スイープで見える大きな変位を、そのまま局所的な制御感度とはみなさない。
2. 同一の目標・初期姿勢・シード・7秒の時間枠で、(A) 第1軸FF＋2秒保持、(B) 第1軸FF＋第1軸FB、(C) 第1軸FF＋第2軸FBを比較する。最初の5秒は従来の線形関節軌道とし、フィードバック補正は到達後の2秒に限定する。後続実験で操作中補正を試す場合も、3条件を同じ時間枠で再評価する。
3. 第2軸FBは局所感度 `b2 = ∂y/∂g` の符号・大きさを用いてスコアを更新する。感度が観測ノイズ以下、符号が変わる、接触状態が変わる、あるいは関節制限に達した区間では補正を停止する。試験開始時は `g ∈ [-0.5,0.5]`、一度の更新 `|Δg| ≤ 0.05` を上限候補とし、実測応答とシミュレーションの制御周期に合わせて確定する。力・接触の指標はまず過負荷や脱落を検出する制限として記録し、ツール誤差と同時に独立制御できるとは主張しない。
4. 共通目標値で、全試行の絶対誤差、物理的に有効な試行のMAE、RL目標範囲に対するCoverage、有効試行率、収束時間、スコア変更量、接触・荷重、転倒・落下を報告する。各方式が個別に選んだ逆写像区間内のMAEだけで優劣を判定しない。初期姿勢別にも分布を示す。
5. 候補4タスクで誤差・保持状態・振動が改善した場合に、同じ固定パラメータ選択規則で15タスクへ拡張する。実機試験前にはShadow Hand Lite上のセンサ種別、符号、単位、遅延、自由空間時の荷重、緊急停止を別途確認する。

## 判定条件と論文の位置づけ

第2軸FBの価値を示すには、FFのみとの比較に加えて、**第1軸FBとの対照**が必要である。改善例がタスク・操作点に限られる場合はその範囲を報告する。第2軸で把持とツール操作量を独立に制御できたという主張は、両出力に対する局所感度と閉ループの実測がそろうまで行わない。主論文の1自由度結果は固定した基準として扱い、この実験の成功・失敗によって後から選び直さない。
